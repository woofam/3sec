3SEC HELP · KITCHEN

3초 키친
사용 가이드

앱에서 메뉴를 결정하고 다음 행동으로 이어지는 기본 흐름을 미리 정리했습니다.

준비 중인 문서입니다. 실제 앱 화면과 기능 검증이 완료된 뒤 버튼명, 화면 이미지, 문제 해결 내용을 최종 확정합니다.
문서 상태: 초안최종 수정: 2026-08-19대상: 3초 키친

1. 재료 선택

냉장고에 있는 재료를 선택하거나 음성으로 입력해 추천의 출발점을 만듭니다.

출시 전 추가할 내용재료 선택 화면 이미지, 음성 입력 권한 안내, 선택 가능한 재료 범위

2. 상황 설정

아이 연령, 식사 상황, 원하는 메뉴 분위기처럼 지금의 조건을 선택합니다.

출시 전 추가할 내용연령별 기준, 상황 선택 예시, 추천 결과에 반영되는 항목

3. 결과 확인

추천 메뉴와 필요한 재료를 확인하고 장보기 또는 배달 같은 다음 행동을 선택합니다.

출시 전 추가할 내용결과 카드 설명, 저장·공유 방법, 추천이 마음에 들지 않을 때의 재선택 방법

4. 문제 해결

앱 실행, 음성 권한, 데이터 저장과 관련된 자주 묻는 질문을 이 영역에 추가할 예정입니다.
